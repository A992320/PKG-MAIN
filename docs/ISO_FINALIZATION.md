# تجهيز نسخة Linux / ISO

هذه الملفات تجعل إعداد النسخة قابلاً للتكرار بعد نقل المشروع إلى خادم أو تضمينه في ISO. نظام PHP في `/iptv/` هو الواجهة الوحيدة؛ لا توجد واجهة ثانية أو مسار تجريبي.

## قبل التشغيل

- انسخ مجلد المشروع إلى `/var/www/html/iptv`.
- تأكد من وجود Apache وPHP وMySQL وFFmpeg.
- ضع إعدادات قاعدة البيانات والمفاتيح السرية في `.env` ولا تضف الملف إلى نسخة عامة أو مستودع.
- شغّل الأمر مرة واحدة بصلاحية المدير:

```bash
sudo APP_DIR=/var/www/html/iptv bash /var/www/html/iptv/tools/iso_finalize.sh
```

ينفذ الأمر الآتي بصورة آمنة عند التكرار:

- يضبط مجلدات الكتابة وملف `.env` بصلاحيات مناسبة.
- يجهز مجلد HLS المؤقت في الذاكرة.
- يفعّل رؤوس حماية Apache وإعدادات جلسات PHP الآمنة.
- يفحص إعداد Apache والخدمات والنقاط الأساسية بعد التنفيذ.

## فحص بعد التثبيت

```bash
sudo APP_DIR=/var/www/html/iptv bash /var/www/html/iptv/tools/iptv_healthcheck.sh
```

يجب إجراء اختبار يدوي من المتصفح لقناة Live وفيديو VOD حقيقيين. فحص الصحة لا يشغّل قناة تلقائياً، حتى لا يفتح اتصالاً بمصدر البث أو يظهر روابطه في السجل.

## ما لا يقوم به النص عمداً

- لا يغير إعداد Restream أو HLS أو قاعدة البيانات.
- لا يفعّل جداراً نارياً تلقائياً، لأن منافذ الإدارة والوصول تختلف حسب الشبكة.
- لا يفعّل `Secure` للكوكيز قبل إعداد HTTPS صالح؛ تفعيله على HTTP سيكسر تسجيل الدخول.

قبل الإتاحة خارج الشبكة المحلية، أضف شهادة HTTPS موثوقة ثم فعّل الكوكيز الآمنة، وحدد سياسة جدار ناري تسمح فقط بالمنافذ اللازمة. بعد اختبار دخول مشترك فعلي، Live وVOD، تكون واجهة `/iptv/` الحالية جاهزة كواجهة النظام الوحيدة.
